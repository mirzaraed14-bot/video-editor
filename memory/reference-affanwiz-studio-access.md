Checked 2026-11-12, read-only, in Claude in Chrome: `studio.youtube.com/?authuser=0` lands on a removed channel ("Rejoining the YouTube
community"); `authuser=1` is a different channel (~1.6K subs); `authuser=2` is blank. AffanWiz's channel id is `UCvL2BJ8OQAPdDe4pSZoGdZQ`,
and its Studio analytics URL returns "you don't have permission" on all three. It probably sits behind a brand-account channel switch.
Switching his active channel is an account action, so don't do it unasked.

**How to apply:** for impressions, CTR, average view duration or traffic sources on AffanWiz videos, ask him for a screenshot or numbers
in one line (the standing ask is CA-003 + CA-011). Public view counts come from youtube.com/@AffanWiz/videos. Related:

Affan, 2026-10-14 (batch 3, six new YESes): "give me the sequencing via text for each video before you start editing."

**Why:** the clip selection and sequencing make the video ("the editing is the sauce on the steak"); a wrong pick costs a whole
build + QA cycle, and in batch 2 one pick (Jeremy) was ranked on titles alone.

**How to apply:** research first (each pick READ ON A TRANSCRIPT), then a PICKS file + a chat message with, per video: the hook
line, each beat in order with the speaker's words (quoted, short), the button line, the length, and one line each on what the
YouTube look and the Instagram look will show. No build starts until he approves; this replaces batch mode's "no storyboard
approval" for the sequencing (the storyboard/graphics still need no approval). Related: [[project-onyx-sample-shorts]],
[[feedback-every-video-better-than-last]].

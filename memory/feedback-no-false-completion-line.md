He was right.

**Why:** he uses the line as a guarantee so he doesn't have to keep asking "is this the best?". A line typed while a known gap is open forces him to keep checking, which is exactly the job he handed over.

**How to apply:** before typing any completion or guarantee phrase he asked for, list every known open item (unsearched witness, weaker default, unconfirmed speaker, missing proof). If any is open, close it first. If it can't be closed, don't type the line; name the gap and why it's open instead. Witness lists include the subject's doctor and management, not only family. Research gaps block the line. A check that can only run on the downloaded source in the build (which person a caption names, one contraction) doesn't block it, provided it is stated plainly next to the line (8 Nov: Affan pushed back when I withheld the line over the MJ brother's name).

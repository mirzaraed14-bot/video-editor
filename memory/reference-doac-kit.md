`projects/_client-scott-clary/_doac-kit/` (README.md there) is the Tuesday DOAC-look pipeline as a reusable kit:
`new_job.py <name> --spans spans.json --hls <master url>` then `run_job.py --job <dir> all`.
Stages: fetch (Scott's own flightcast HLS, stream copy) → audio → asr (WhisperX GPU under lock.sh gpu) → spec (spans snapped to the words, auto-chunked captions, card detection) → shots (head lock) → vaudio (−14 LUFS static chain) → build30 (shadow ON) → qa30 → plain30/qashadow → proof30 → plate → chronos (Topaz 2x per take) → build60 → qa60 → deliver (X:\Claude Projects\Exports).

**Proof:** run on the Tuesday inputs (`_doac-selftest`) it reproduces the delivered `doac.check30.shadow.mp4` byte for byte, plus the audio, QA and timing logs identically (2026-11-16).
**Why it exists:** Affan's overnight brief 2026-11-16 (a second Scott own-talk Reel with nobody to ask) — see [[feedback-scott-ig-minimal-format]]. The look and the shadow are his picks, not a standing rule for other strands.
**How to apply:** use the kit for any new Scott own-talk Reel; a decision it makes alone is logged at the top of the job's RUN.md.

**Tracked-crop jobs and the 60 fps final (2026-11-18, Stygar Reel):** the kit's `build60` composes over a plain Chronos plate with static crops, so it drops a job-local tracked picture, motion graphics and a custom shadow. The working recipe (all in `projects/_client-scott-clary/stygar-recorded-firing/work/v2/`): `build_v2.py --make-plate` (clean tracked window) → kit `plate_segments.py` → `topaz-iris.py --no-enhance --no-stab --fps-mult 2 --segments <takes>` under `lock.sh gpu` (wait for the lock dir to be free first so its 90-minute stale takeover never steals a live holder) → kit `align60.py` → job-local `build60_v2.py` (graphics at t=k/60, captions at 2x the 30 fps frames) → kit `qa60.py` + `qa60_extra.py`. Never run `run_job.py` stages on such a job (it rewrites RUN.md's STATUS line to a kit resume command). Chronos quirk: the longest take (770 frames) came back with its "original" slots 0.15 frame (5 ms) early (still evenly spaced), the other takes exact; qa60's worst-block number then spikes on fast hands only, and it still says PASS. Kit follow-up still open: a tracked-crop 60 fps path in the kit itself. Related: [[feedback-keep-person-centred]], [[reference-topaz-video-ai]].

**Second tracked-crop job, a 1080p source in two windows (2026-11-19, "You Don't Need To Be Elon", `scott-you-dont-need-to-be-elon`):** the Stygar fork (`work/v2/`) needs a copy per job and was adapted for a 1080p feed: sub-pixel float crop + one Lanczos-4 `warpAffine` (`winwarp.py`), `calib.json` per-span x calibration from the RENDERED window. Spans far apart in the episode: fetch two windows losslessly (FFV1/PCM, `work/fetch2.py` + `join2.py`), never concat stream-copied HLS windows (hidden pre-roll packets). **A/V sync trap:** an accurate-seek HLS decode stamps the first video frame 0.0333 s after the audio, but the true offset is 0.017 s (the CDN starts video at 1.500, audio at 1.483; 0.0333 is a 1/30-tick rounding): trimming 1/30 runs the audio 16.7 ms early. Measure with `-copyts` plus an audio cross-correlation before trusting a fetch. Kit bugs to remember (not patched): `make_spec.refine_end` cuts a word at a stop closure (set `fb` by hand and check every span end on the 10 ms envelope); `plate_segments.py` reads arm sweeps as cuts and `align60.py` reads its takes from `plate_segments.json` (set the takes by hand = the span starts, and re-run align60 after); on a source with repeated frames (24-36 % on Scott's Pineda feed) kit `qa60` says CHECK by design (Chronos replaces repeated frames), check with a source-repeat overlap, corner blocks and the Topaz token error instead. Captions: the kit prints the ASR's casing, so fix sentence starts and names in `words.json`; the vendored EB Garamond subset has no "?" glyph.
